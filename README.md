# CARD PORT

ログイン不要で閲覧できるカード通販サイトのフロントエンドです。本番サーバーの構築・公開は行っていません。

## 開く

`dist/index.html` をブラウザーで開くだけで使用できます。Node.js がある場合は、このフォルダーで `node preview.cjs` を実行し、表示された URL を開くこともできます。

## 実装済み

- 商品一覧、商品詳細、カード名検索、価格・在庫・商品タイプの絞り込み、並び替え
- 右上のログインボタンと入力フォーム（認証は未接続。送信・保存しません）
- デモカートの追加・数量変更・削除・合計計算。ブラウザーのローカルストレージに保存
- スマートフォン表示、キーボード操作、ダイアログの Escape 終了

商品データは `dist/products.js` にまとめてあります。ポケモンカード6点のみのデモです。他のカテゴリーとBOXにはまだ商品を登録していません。価格・在庫・状態は架空です。店名は仮称です。

## サーバーを作るとき

商品取得API、サーバー側認証・セッション、会員登録、在庫管理、注文・決済を接続します。現在のデモ管理者認証を本番公開に使用しないでください。金額と在庫は必ずサーバーで再検証し、ブラウザーの値を信用しない設計にします。実際に販売する際の送料、返品条件、運営者情報等も別途設定します。

## 管理者ログイン（ローカルデモ）

- ID: `admin`
- パスワード: `CardPort2026!`
- 右上の「ログイン」→「管理者としてログイン」、またはページ下部の「管理者ログイン」から開きます。
- 同じ `index.html` 内の管理画面から、カード名・カードゲーム・タイプ・価格・在庫・シリーズ・レアリティ・画像URL・ラベルを追加／編集できます。
- 画像はHTTPS URLに対応します。空欄も可能です。
- 管理者ログインはページ再読み込みで解除されます。認証情報がフロントエンドにあるため、アクセス制御としての安全性はありません。本番はサーバーで認証・権限管理します。

## デモ注文とシリアルナンバー

カートから「デモ注文を確定する」を押すと、注文1件ごとに `CP-日付-ランダム番号` を発行します。商品ごとの番号ではありません。注文内容と番号は注文履歴および管理画面の注文一覧で再確認できます。注文時点の商品名・価格を保存し、その後の商品編集でも注文内容は変わりません。確定時に在庫を減らし、カートを空にします。決済・発送・個人情報収集は行いません。

保存先はこのサイトを開いたブラウザーのローカルストレージ (`card-port-store-v1`) です。他の端末・ブラウザー・URLでは共有されず、閲覧データを消すと失われます。ブラウザーが保存を拒否した場合、注文確定や商品保存は成功扱いにしません。別タブで更新を検出した場合は再読み込みが必要です。本番ではデータベースのトランザクションと注文番号の一意制約が必要です。
